# Калькулятор натяжных потолков — VK Mini App

React + TypeScript + Vite. Включает прайс из 16 позиций и предварительный расчёт.

## Публикация на GitHub Pages

1. Создайте репозиторий `-potolok-calculator` и загрузите в него все файлы проекта.
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **GitHub Actions**.
4. Откройте вкладку **Actions** и дождитесь успешного запуска `Deploy VK Mini App to GitHub Pages`.
5. Адрес сайта будет: `https://faister98-design.github.io/-potolok-calculator/`.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

## Подключение к VK

В настройках VK Mini App укажите опубликованный HTTPS URL в полях URL для мобильной и десктопной версии.

Кнопка отправки использует `VKWebAppSendPayload`. Для фактической доставки события нужно проверить привязку приложения к нужному сообществу и настроить обработчик события на стороне сообщества (бот/Callback API). Один только вызов Bridge не создаёт серверного обработчика.

## Важно про цены

В прайсе указаны 16 позиций пользователя. Для «Сборка и установка люстры» в расчёте используется минимальная цена 2 000 ₽ за штуку; окончательная цена зависит от сложности. Все цены и правила можно менять в `src/App.tsx`.
